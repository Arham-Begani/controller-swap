# Public release scope

This is a reviewed copy of a completed local interface revision, not a dump of the
development machine. Original source, databases, failed logs and earlier archives
remain preserved locally.

Included: the standard-library application, original static interface, licensed
fonts and notices, optional sample-only private-network preview adapter,
self-contained unit/API and browser checks, screenshots and honest research status.

Excluded: saved working databases, raw conversation/request/response archives,
machine-specific logs, personal contacts, local network addresses and active
preview links, runtime tokens, model weights, downloaded runtimes, caches and
bulky development archives. The generic RFC1918 ranges and loopback examples in
source are networking rules, not disclosure of a user's address.

Three local-only test modules are excluded: archived-response UI replay,
source-bound development-plan replay, and runtime stream diagnostics. Their
supporting private archives/runtime tools are not part of this release. Their
failures and limits are documented in research status rather than omitted from
the scientific account. Public-copy verification reports only checks that can run
from this tree.

Initial Git commits use current publication time and coherent groups of files.
There is no reconstructed or backdated development history, artificial per-file
commit inflation, or claim that AI-assisted work was written unaided. No root
license has been invented; third-party notices remain intact.
