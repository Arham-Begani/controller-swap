# Competition provenance and submission destination

Checked against the official pages on 6 November 2026:

- [Agent Attribution Hackathon](https://apartresearch.com/sprints/agent-attribution-2026)
- [Submission and prize terms](https://apartresearch.com/sprints/prize-terms)

The online event is November 27–29, 2026, with a stated submission deadline of
November 29 at 11:59 PM Anywhere on Earth. AI assistance is permitted; authors
remain responsible for accurate claims and references. Only weekend work is judged.
Earlier code must be identified as preexisting in both README and report.

The required deliverable is a research PDF using the official template, up to
eight pages before references and appendices, with an abstract, authors,
affiliations and limitations/ethical discussion. A public repository is optional.
The event also warns that publication of datasets and methods will be limited;
final security rules and the template are still marked forthcoming.

**Submission destination:** the built-in **Submit your project** form on the
[official Sprint page](https://apartresearch.com/sprints/agent-attribution-2026).
Form markup is present, but this is a future event and an accepting submission
window has not been verified. The signup form is a separate registration action.
Nothing has been registered or submitted, and no terms have been accepted.

This public release contains a generic toy workbench, not official logs, held-out
challenge data, participant records or real-world incident evidence. Recheck the
rules before adding event materials or presenting new research as publishable.
